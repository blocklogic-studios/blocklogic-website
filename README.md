# Blocklogic Studio website

Static site for Netlify.

## Deploy

1. Import this repo in Netlify
2. Publish directory: `.`
3. Optional custom domain — then align `canonical` URLs and `sitemap.xml`

## Google Search Console

Add the live URL, verify ownership, submit `/sitemap.xml`.
